# Architecture Decision Records

Each significant architectural decision is recorded as a short Markdown file in this folder. An ADR is written when the decision is implemented, and it is not edited afterwards: a changed decision gets a new ADR that supersedes the old one.

## How to add one

1. Copy [`000-template.md`](000-template.md) to `NNN-short-title.md`, using the next free number.
2. Fill in every section. Keep it to one page.
3. Add it to the index below in the same pull request.
